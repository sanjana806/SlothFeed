🦥 SlothFeed Architecture

An autonomous reading janitor designed for Hacktoberfest 2026. Engineered to demonstrate the sovereign power of open-weight LLMs running on predictable cloud runtimes.

Render Blueprint Deployment

Orchestrated declaratively via render.yaml as a Docker Web Service + Background Worker with integrated health checks and zero configuration drift.
